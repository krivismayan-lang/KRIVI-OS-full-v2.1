# KRIVI-OS-full-v2.1
A high-performance, high-density 4x3 Touch Micro-OS for the ESP32 Cheap Yellow Display (CYD). Features a 5-second diagnostic boot sequence, live Wi-Fi weather, real-time 3D ISS orbit raycasting, Helix MP3/MP4 multimedia decoding, a standalone Standby Desk Clock, and an interactive Raspberry Pi terminal bridge over USB serial.
